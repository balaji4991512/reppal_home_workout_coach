# Changing a workout while it runs (draft, defaults chosen; change anything)

Asked for: go back to an earlier set or exercise to fix a set saved by mistake, and skip or replace an exercise during
the workout.

## Moving about
- Under the progress bar: a back arrow, "Push, exercise 2 of 7" with a down arrow, and a forward arrow. The arrows move
  one exercise; tapping the middle opens a list of every exercise with how far it got (Not started, 2 of 3 sets,
  Done, Skipped, Skipped after 1 set, Stopped for pain). Tapping one opens it.
- An exercise with nothing left to log (all sets in, skipped, or stopped for pain) shows its sets, what happened, and a
  button to the next exercise still to do. Once every exercise is complete the button is "Finish workout".
- Saving the last set of an exercise moves on to the next exercise still to do (after it, then any before it); saving
  the last set of the whole workout finishes it, as before.

## Correcting a set
- Each done set (the green pill) can be tapped: a sheet shows its reps, its weight (owned dumbbells) and how it felt.
  Save changes, or Delete this set (asked once more). A deleted set can be done again; the exercise opens up again.
- The set keeps the target it was logged against. The next set's target is worked out again from the corrected sets,
  as if they had been saved that way, so a wrong "easy" no longer moves the weight up.
- Pain tapped by mistake: an exercise stopped for pain offers "Pain was a mistake, carry on", which takes it back into
  the workout and keeps it in the plan.
- A finished workout can still be corrected afterwards from its saved record, as before.

## Skip
- "Skip" (beside How to do it) leaves the exercise out of this workout and moves on. Its plan stays as it was for next
  time; it is not pain and nothing is excluded. Sets already logged on it are kept and count as done work.
- A skipped exercise can be opened again: "Do it after all".
- The last exercise left cannot be skipped if nothing at all has been logged (that would save an empty workout); leave
  the workout instead.
- Workout done shows a skipped exercise as "Skipped. Was 3 × 12 at …", "Skipped this time, so it stays the same for next
  time."

## Replace
- "Replace" (while nothing is logged on the exercise, or while it is still in progress) opens the exercises for the
  same muscle that the equipment allows and that are not in this workout, the plan's own exercise first if it was
  replaced. The same list as the Week page swap.
- Choose "This workout only" (default) or "From now on" (the same as swapping it on the Week page). Sets already logged
  on the old exercise are dropped, and the sheet says so.
- The new exercise starts from its own stored plan (or a starting one) and progresses from what is done today.

## Weight chips
- Above "Reps you did", a weighted exercise has "Weight you used": the owned dumbbells nearest the set's target, two
  either side (more on one side at the ends of the rack), the target chosen to start. Tapping one logs the set at that
  weight; tapping it again goes back to the target. It also changes the weight of a spoken or typed note.
- The chips follow each set: after saving, they start again from the next set's target (a ramp's next step, or the
  weight just used). The weight saved is what the next set follows, as before.
- Reps you did now runs from two over the target to three under, so a set that beat the target can be logged with a tap.
